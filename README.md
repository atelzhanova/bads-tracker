**Трекер БАДов — краткая справка**

---

**Где что лежит**

| Что | Где |
|-----|-----|
| Файл приложения | github.com/atelzhanova/bads-tracker |
| Ссылка для входа | atelzhanova.github.io/bads-tracker |
| Данные (облако) | Google Sheets «Трекер БАДов», лист «data» |
| Данные (локально) | Браузер телефона (localStorage) |
| Скрипт синхронизации | Google Apps Script в том же аккаунте |

---

**Как работает синхронизация**

- При каждой отметке данные сохраняются локально мгновенно
- Через 1,5 сек отправляются в Google Sheets
- При открытии на новом устройстве — загружаются из Sheets автоматически
- Без интернета — работает офлайн, синхронизируется при подключении

---

**Бэкап**

Раз в месяц: **Админ → Экспорт в JSON** → файл сохранить в Telegram (Избранное).

Этого достаточно — Google Sheets уже является резервной копией.

---

**Переход на новый телефон**

1. Открыть `atelzhanova.github.io/bads-tracker` в Chrome
2. Данные загрузятся из Google Sheets автоматически
3. Добавить на главный экран

---

**Обновление приложения** (если выйдет новая версия)

1. Скачать новый `index.html`
2. Загрузить на GitHub в репозиторий `bads-tracker`
3. Страница обновится через 1–2 минуты

---

**Важно**

- Всегда открывать через `atelzhanova.github.io` — только там данные сохраняются в облако
- Не открывать файл напрямую с телефона через файловый менеджер
